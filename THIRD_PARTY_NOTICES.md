# Third-party materials

The root MIT licence covers original Argus Mara code and documentation contributed to this project. It does not relicense third-party data, images, fonts, libraries, skill instructions or online services.

- `ui/assets/world_cables.json`: historical TeleGeography cable reference; CC BY-NC-SA 3.0. Non-commercial/share-alike restrictions remain. Replace or separately license this data for commercial redistribution.
- `ui/assets/world_ports.json`: NGA World Port Index public reference data; preserve embedded source metadata.
- Irish port catalogue: Marine Atlas / MIDA, CC BY 4.0; preserve attribution and source IDs.
- Natural Earth coastline/planning geometry: public domain. Other map backgrounds retain their provider terms and attribution.
- `demo/imagery/`: published imagery derivatives and explicitly labelled fictional/simulated overlays. The pack's README and manifests specify source credits and reuse terms for each item.
- Copernicus/Sentinel, Esri, EMODnet, OpenSeaMap and NASA imagery/map materials retain their respective terms. A cached tile is not automatically licensed for redistribution.
- OpenSanctions maritime data is an optional local download under CC BY-NC 4.0. Global Fishing Watch data/API use is subject to its own terms. Neither a personal API token nor the team's observation archive is distributed.
- `trailer/public/fonts/`: Barlow Condensed and DM Sans, with SIL Open Font License texts beside the files.
- Third-party skills under `skills/` retain their upstream terms and attribution. JavaScript/Python dependencies retain their package licences; Remotion has its own usage/licensing terms.

See [source notes](docs/sources.md), embedded metadata in `ui/assets/`, [imagery provenance](demo/imagery/README.md) and the dependency manifests for details. Do not assume the code licence grants a right to redistribute an external dataset or use a provider service.
