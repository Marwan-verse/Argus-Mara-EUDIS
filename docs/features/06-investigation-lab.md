# Investigation lab

**Where:** **+ → Investigation lab**, or the magnifying-glass button on the left
toolbar. Private sessions require evidence permission.

| Tab | What it does |
|---|---|
| Timeline | Combines retained AIS fixes, gaps, observed identity changes, loaded satellite associations and analyst reports. |
| Encounters | Reviews selected vessels for parallel travel, possible rendezvous and repeated close approaches. |
| Challenge | Creates an editable fictional branch with new speed, course, AIS availability and wind settings. |
| Evaluation | Compares Brain with a basic 1 nm proximity alarm on five labelled fictional stories. |

**Timeline:** select a vessel, refresh, inspect key events or all fixes, open a
source record, show its map location, or export the timeline. Unassociated
observations remain separate.

**Encounters:** choose exercise or received tracks, select 2–40 vessels and press
**Review selected**. Select a finding and move the replay slider. Port-area
patterns stay context-only; findings do not prove coordination.

**Challenge:** edit inputs, advance one/five minutes or play. Alerts and assumed
observation options update. Hidden AIS-off motion cannot enter observed evidence.

**Evaluation:** run the comparison and export per-story results. Negative lead
time means the alert arrived after corridor entry. These are development
examples, not measured operational accuracy.

Each tab has an export option. Challenge state remains in app memory when its
panel closes; application exit removes it.
