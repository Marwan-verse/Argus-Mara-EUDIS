# Map and navigation

**Where:** main map, left/right toolbars, **Search**, and **+ → Map layers**.

| Feature | What it does |
|---|---|
| Pan and zoom | Drag the map; use the wheel, trackpad or zoom buttons. Optional macOS support adds pinch zoom. |
| Map backgrounds | Choose the tactical chart, satellite imagery or offline coastline. Online detail is cached locally. |
| Map layers | Show/hide ships, stale fixes, real alerts, simulated alerts, radar, cables, ports and other overlays. |
| Search | Press **Ctrl+K** to find ships, MMSIs, vessel types, ports, saved views or coordinates. |
| Port directory | Search ports, inspect their source/category and centre the map on a selection. |
| Cable directory | Search historical reference routes, select one and fit it on the map. |
| Saved map views | Open regional presets; save, reopen or delete your own views. |
| Measure distance | Select two points to measure kilometres and nautical miles. |
| Notes and pings | Add local map notes or a temporary, coordinate-based ping. |
| Layout | Open, close, move and resize panels; move tabs between docks. **F11** toggles fullscreen. |
| Reduced motion | Reduce panel transitions and ping animation through **Map layers**. |

Reference maps and historical cable routes are approximate display material.
They are not navigation charts or surveyed cable positions. Preferences and
saved views are local; map notes are session-local.
