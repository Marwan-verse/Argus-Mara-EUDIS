# Weather and magnetics

**Where:** weather icon or **+ → Live weather**; magnet icon or
**+ → Magnetics**.

| Feature | What it does |
|---|---|
| Live weather | Optionally fetches Met Éireann model forecasts: wind, gusts, temperature, rain and pressure. |
| Rain and cloud | Draws forecast conditions over the visible map, including supported forecast hours. |
| Wind layer | Shows direction arrows and wind speeds. |
| Geomagnetic context | **Live magnetic data** displays NOAA Kp and Valentia magnetic observations, with a storm-tier summary. |
| Cached magnetic status | Shows the last saved reading when available, labelled with its observation time. |
| Seabed search planner | Uses the exercise vessel or selected alert to estimate where to search for an anchor or chain after suspected dragging. |
| Planner inputs | Adjust assumed water depth, anchor mass and search platform: surface vehicle, underwater vehicle or drone. |
| Planner output | Shows a search corridor, priority locations, line spacing, distance and duration estimates. Toggle it on the map or export GeoJSON. |

Weather and magnetic feeds are optional and need internet access. Rain/cloud
layers are forecasts, not weather radar. Storm context does not raise, lower or
clear alerts. The seabed plan uses assumptions; it does not detect an anchor or
prove cable damage. Simulated response wind is a separate exercise control.
