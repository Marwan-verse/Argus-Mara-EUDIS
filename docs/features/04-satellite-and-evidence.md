# Satellite and evidence

**Where:** radar icon or **+ → Satellite analysis**; **+ → SAR next step**.

| Feature | What it does |
|---|---|
| Search and import | Search dated satellite scenes, load a bounded image crop, reopen saved crops, or import supported GeoTIFF/AIS files. |
| Manual image review | **Analyse image** requests AI-assisted contact suggestions when configured. |
| Coast Watch | **Start scan / Stop** controls a rolling Irish coastal image queue; shows coverage, processing status and budget. |
| Radar contacts | Connect Global Fishing Watch and fetch published Sentinel-1 detections. These are delayed historical observations. |
| Image-time AIS | **AIS at image time · free** compares imagery with available AIS from its acquisition time. |
| Selected contact | Inspect source pixels, candidate identities, matching uncertainty and a candidate's latest received position. |
| Map overlays | Toggle the image, AIS, AI observations and radar layers. |
| Analyst outcomes | Record follow-up, insufficient evidence, false detection, association error, reviewed/no concern or reopen through incident review. |
| Next satellite look | **SAR next step** lists planned Sentinel-1 coverage and checks whether frames reached the public catalogue. |

AI analysis needs configuration and uses the persistent pilot budget. A scan left
enabled may resume at the next launch. Cloud, clutter and missing AIS limit what
can be concluded. A planned pass is not a confirmed acquisition; an unmatched
contact is a lead, not proof of transponder shutdown.
