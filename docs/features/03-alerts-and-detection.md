# Alerts and detection

**Where:** **Incidents** on the left; click a row or alert marker to review it.

| Feature | What it does |
|---|---|
| Priority queue | Groups Critical, High, Medium, Low and closed/reviewed items. Low items can be folded away. |
| Real alerts | Checks recent team AIS history near illustrative cable routes; real alerts are labelled **REAL**. |
| Exercise alerts | Shows fictional replay stories, separately labelled. The simulated-alert switch hides them. |
| Other review leads | Includes satellite/AIS findings, history checks and analyst vessel reports. |
| Explanation | Shows the score, contributing indicators, source quality, uncertainty and suggested review steps. |
| Analyst decisions | Review, acknowledge, escalate, withdraw or reject as offered; enter reasons where required. |
| Changing evidence | Real alerts can request review again when severity rises. A cleared, unseen alert stays visible until reviewed. |

The rule engine covers cable approach, slowing/turning, anchoring or drift near
a line, loitering, repeated passes, unusual AIS positions, declaration/motion
disagreements, stops away from ports, and available identity/watchlist context.
Marine Notice checks identify named survey/repair work, with exceptions for
conflicting evidence. Radar/AIS rules run only in contexts with suitable data;
the frozen main exercise keeps its agreed timing.

A rule can use only the fields and history actually available. Severity means
review priority, not a probability of hostile intent. Real alerts offer no
fictional responder dispatch.
