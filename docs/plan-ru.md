# План простыми словами (Argus Mara)

## Что мы делаем
Программа следит за кораблями вокруг Ирландии и замечает тех, кто может повредить подводные кабели: тащит якорь по дну, выключил маячок, врёт о себе. Когда такой корабль появляется, программа включает таймер «до кабеля осталось 1 ч 20 мин» и показывает, кто успеет туда добраться. Решение всегда принимает человек.

## Где мы сейчас
- Идея и название есть. Команда есть: кибер-команда, капитан — Mykhailo.
- Ждём от организаторов подтверждения, что нам дали место. Но начинаем уже сейчас. Сделанное заранее показывать можно, если честно сказать, что было готово до хакатона.
- До хакатона 18 дней: он проходит 15–17 октября.

## Шаг 1. Сегодня–завтра: созвон команды (1 час)
- Рассказать идею. Можно открыть README на GitHub.
- Раздать направления:
  - **Данные** — собирает всё: корабли, кабели, глубины, санкционные списки.
  - **Мозг** — логика: замечает подозрительное поведение и считает таймер.
  - **Космос** — спутниковые снимки: находит корабли без маячка и сверяет их размер.
  - **Экран** — то, что увидит жюри: карта, карточка тревоги, кнопки.
  - **Капитан** — история и питч, письма, эксперты, организаторы.
- Добавить всех в репозиторий на GitHub и в Discord.

## Шаг 2. Запустить «слежку» — самое срочное
**Что это.** Каждый корабль сам по радио сообщает, где он находится. Это система AIS, и её данные открыты: так работают сайты вроде MarineTraffic. Сервис aisstream.io бесплатно пересылает эти сигналы через интернет. Наша программа круглосуточно слушает корабли вокруг Ирландии и сохраняет их в файлы.

**Зачем.** К хакатону у нас будут 3 недели своих данных. На них система учится, что «нормально», и на них же мы считаем ложные тревоги. Это главные цифры для жюри.

**Как.** Программа уже готова и лежит в папке `recorder/`.
1. Зайти на aisstream.io через GitHub и скопировать ключ (API key). Ключ никому не показывать.
2. Найти компьютер, который не выключается. Лучше всего подходит маленький облачный сервер, примерно 4–6 € в месяц. Ноутбук засыпает, поэтому годится только для проверки.
3. Скачать проект и поставить библиотеки:
   ```bash
   git clone https://github.com/classified-mick/Defence-Hackaton.git
   cd Defence-Hackaton
   python3 -m pip install -r recorder/requirements.txt
   ```
4. Запустить в фоне:
   ```bash
   AISSTREAM_API_KEY=ваш_ключ nohup python3 recorder/recorder.py >> recorder.log 2>&1 &
   ```
5. Через 15 минут проверить:
   - `python3 recorder/check.py` покажет, сколько кораблей записано;
   - `python3 recorder/map.py` создаст файл `map.html`. Откройте его: там все корабли на карте.

Подробно — в `recorder/README.md`.

## Шаг 3. Неделя 1 (28 сентября – 4 октября): «скелет»
Цель — первая работающая версия, пусть некрасивая.
- **Данные:** кабели и глубины скачаны, отмечены участки кабелей на мелководье (там якорь достаёт до дна).
- **Мозг:** простое правило «корабль резко сбросил скорость над кабелем на мелководье» и первый таймер.
- **Космос:** один спутниковый снимок — какие корабли видны на радаре, но молчат по AIS.
- **Экран:** карта с кораблями и кабелями.
- **Капитан:**
  - письмо организаторам (вопросы готовы);
  - письмо команде Sea-Scan в Trinity (шаблон готов);
  - найти одного «морского» эксперта на 20-минутный разговор.

**Проверка в воскресенье 4 октября:** всё это видно на экране.

## Шаг 4. Неделя 2 (5–12 октября): таймер и «космос»
- Таймер «до кабеля» и панель «кто успеет»: самолёт ✅, корабль ❌ и так далее.
- История с вымышленным танкером: выключил маячок → нашёлся на снимке → свернул к мелководью → замедлился → тревога.
- «Паспортный контроль из космоса»: размер корабля на снимке не совпадает с размером, который он о себе сообщает.
- Пакет доказательств одной кнопкой.
- Две цифры для жюри:
  - сколько ложных тревог в день у нас и у простого правила;
  - за сколько мы предупредили бы в случае Eagle S.

**Проверка в понедельник 12 октября:** вся история проигрывается от начала до конца. Что не работает — выкидываем.
