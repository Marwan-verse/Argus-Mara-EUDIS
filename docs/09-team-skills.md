# 9. Downloadable teammate skills

The repository contains two portable Codex skill folders:

| Skill | Use it for | Path |
|---|---|---|
| `argus-codebase` | Python, JSON contract, module boundaries and integration | [`skills/argus-codebase/SKILL.md`](../skills/argus-codebase/SKILL.md) |
| `argus-interface` | Browser replay, offline assets and evidence presentation | [`skills/argus-interface/SKILL.md`](../skills/argus-interface/SKILL.md) |

Teammates can download the repository, then copy either whole folder to their Codex skills directory (`~/.codex/skills/` on macOS/Linux, `%USERPROFILE%\.codex\skills\` on Windows). Restart Codex or begin a fresh session so it discovers the new skills. The skills also work as readable team instructions without installing them.

Keep the `skills/` folders in the same change as their corresponding architecture updates. They point to repository files rather than duplicating the complete documentation. If a teammate uses another coding assistant, start with `AGENTS.md`, `CLAUDE.md` and `docs/07-architecture.md`.
